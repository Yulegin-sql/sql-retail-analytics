# sql-retail-analytics

SQL-анализ розничных продаж: топ товаров, выручка по месяцам, оконные функции, VIEW, оптимизация



\# 📊 SQL-анализ розничных продаж (Online Retail II)



Анализ данных интернет-магазина на PostgreSQL. Выявлены топ-товары, динамика выручки, портрет ключевых клиентов и перспективные рынки.



\## 🎯 Цель проекта



Продемонстрировать навыки написания сложных SQL-запросов: от базовой агрегации до оконных функций, CTE и оптимизации через индексы.



\## 🛠 Стек технологий



\- \*\*PostgreSQL 18\*\* — СУБД

\- \*\*DBeaver\*\* — клиент для работы с БД

\- \*\*SQL\*\* — язык запросов



\## 📁 Структура репозитория



sql-retail-analytics/
